# Python ML Mini-Projects

Ten self-contained beginner-to-intermediate Python and machine learning projects.

## Quick Start

```bash
cd python-ml-mini-projects
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install scikit-learn pandas numpy seaborn matplotlib requests beautifulsoup4
```

Each folder runs independently:

```bash
cd project-01
pip install -r requirements.txt
python main.py
```
